QGIS Canada Branding
====================

Repository to hold source files (.svg, etc) of all branding materials
(such as logos, stickers, flyers/pamphlets, banners, etc).

Rules
=====

1. Please always use Open Source software when creating/editing branding materials
   (such as Inkscape for creating SVGs, GIMP to create PNG, etc).  Thank-you.

2. Since these materials will be used for printing, please always include a source
   .SVG 

3. If you want to use an existing SVG, please use one that is license-free such as
   from Wikimedia Commons: https://commons.wikimedia.org/wiki/Main_Page
